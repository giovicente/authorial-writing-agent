# Presenting My PERT Project

I have completed a personal project: a command-line application that helps developers make more accurate estimates using the PERT technique.

Estimating how many days a task will take is difficult and uncomfortable, but unavoidable.

I first learned about this technique through *The Clean Coder* and found it to be a more accurate way to provide and request estimates.

With this project, I practiced and improved skills in calculation—such as implementing a square root function for `BigDecimal`—project management through more reliable estimates, clean code by using SonarQube as a linter, clean architecture with layers, Java Streams, unit testing, code coverage with JaCoCo, and artifact generation with Maven. I built and ran the application without IDE shortcuts, inspired by [Leandro Cavallari](https://www.linkedin.com/in/leandro-cavallari/pt/).

The repository is available at [https://lnkd.in/dERHcVdQ](https://lnkd.in/dERHcVdQ). Stars and contributions are welcome!
